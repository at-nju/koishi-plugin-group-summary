# 用 Cloudflare Access 与 OIDC 身份源做群成员闸门

站点与数据域名都放到 Cloudflare Access 后面：网页域名对指定 OIDC 身份源的所有用户放行，数据域名只接受 Service Auth 请求，网页经同域 `/data` 代理转发读取，避免跨域 Cookie 与 CORS 限制。OIDC 平台固定返回同一用户身份，Access 侧不需要成员名单，也只统计一个身份，不会触达免费版 50 用户上限。

这个选择把"谁能访问"的判定整体交给 OIDC 平台：平台放行策略过宽或允许开放注册时，闸门随之失效。固定身份也意味着站点将来无法区分访问者，对当前只读总结站没有影响。
